# Archived exploratory provenance

These JSON files are immutable copies of manifests produced by the exploratory
ChEMBL REST snapshot workflow on 2026-10-20. The corresponding raw, processed,
prediction, and checkpoint files remain git-ignored because they are large or
regenerable.

The archive supports the numbers in `docs/exploratory_results.*`. It is not a
confirmatory evidence package: every relevant manifest explicitly records
`confirmatory_eligible: false`, and the dataset contains no VietHerb bags.
